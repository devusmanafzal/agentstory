NORTHWAY: Activation Planning Partner

NORTHWAY is a fictional contemporary fashion retailer used for workshop learning. This page introduces the company context and one coherent use case that progresses from Prompt to Skill, Agent Builder, and Copilot Studio.

Company context

NORTHWAY operates across Northern Europe with priority categories in denim, knitwear, outerwear, and essentials. Teams want faster, better activation decisions while protecting full-price perception.

MarketsSE, DE, NL, DK
AudienceUrban fashion customers (20–34)
TeamsMarketing, CRM, E-commerce, Merch, Commercial
Current painManual planning across fragmented inputs

Use case in one line

Create a monthly activation recommendation by combining sales, campaign performance, budget mix, competitor moves, and customer signals — then turn it into decisions with owners.

Journey across capabilities

1

Prompt

One strong answer from one person, one moment in time.

2

Skill

Repeatable method with references, templates, and output structure.

3

Agent + 2 skills

Routes between full planning and competitor-focused mini analysis.

4

Copilot Studio

Adds triggers, approvals, write-back, and follow-up tasks.

Business value shown to audience

  • Less manual reporting and planning overhead
  • More consistent cross-market activation decisions
  • Faster path from insight to action
  • Clear owner accountability and decision trail

Artifacts prepared

  • One mega prompt for baseline output
  • Primary skill: activation-planning-kit
  • Mini skill: competitor-signal-brief
  • Agent Builder package with skill-routing guidance
  • Copilot Studio flow docs (trigger, approvals, logging, tasks)

Session framing

“Prompting is a start. Skills make quality repeatable. Agents improve team reuse. Copilot Studio operationalizes the workflow.”
