Recommendation wizard

Choose which optional customer and deal fields the advisor asks for.

The wizard always starts with Copilot licences, then the customer-journey questions. Switch on the optional fields below to ask for them in a “Deal details” section at the end. All are OFF by default.

Recommendation output

Control the actions available on the completed recommendation.

Allow Print / PDF on the recommendation
When ON, sellers see a “Print / PDF” button. The printout contains only the recommended package — no header, wizard, “How it works” or footer. Default: ON.
