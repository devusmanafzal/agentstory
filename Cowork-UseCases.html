How each task is priced

Cowork is billed in usage-based Copilot Credits on top of the Microsoft 365 Copilot licence, at $0.01 per credit (Pay-As-You-Go) — with a discounted P3 commitment rate for predictable volume. Every task's cost is the sum of four inputs:

Model Use+ Context Retrieval+ Tool Calls+ Runtime= Credits for the task

⚠️
Budget-planning rule: a small number of Heavy analyses per power user drives the majority of total spend. Always model the high end of the Heavy range — using the midpoint understated real deployment budgets by 20–40%. Plan for power users, control with tenant / group / user spending caps and alerts.
🔒
Confidentiality/Governance note for ARKET: Cowork operates inside the Microsoft 365 trust boundary, respects existing permissions, and routes prompts, responses and generated artifacts through Microsoft Purview controls including audit, DSPM, sensitivity-label inheritance, encryption/RMS, Insider Risk Management, Communication Compliance, eDiscovery and Data Lifecycle Management. ARKET data is not used to train the models. For European operations, OpenAI-operated GPT 5.6 is included in the EU Data Boundary; Anthropic models are outside the EU Data Boundary and are off by default in the EU, EFTA and UK unless an administrator opts in.

Plan budget by user type

Combine how many people sit in each profile with their task mix to size a deployment. As an illustration, a 200-user org running ~20 Light, 10 Medium and 2 Heavy tasks per user per month lands near $270k/year at PayGo — reduced with a P3 commitment.
